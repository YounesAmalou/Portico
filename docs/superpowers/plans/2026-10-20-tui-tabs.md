# TUI Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hosts, Tunnels and Containers become three tabs switched with `1` `2` `3` and Tab, and the tunnel form's Host field gets the ProxyJump suggestion dropdown.

**Architecture:** `UiState` gains a `tab: Tab`; a `tab_key` step before the existing routing handles the global keys when the active tab is browsing. `TunnelsScreen` and `Panel` lose their `Leave` actions, draw into a given area, and report whether they are browsing. The dropdown's state and drawing move to `src/tui/dropdown.rs`, shared by both forms. The containers panel gets a target line and a `picker::Single` target picker.

**Tech Stack:** Rust 2024, ratatui and crossterm as already used. No new crates.

**Spec:** `docs/superpowers/specs/2026-10-20-tui-tabs-design.md`

## Global Constraints

- No new dependencies; the CLI is unchanged.
- Before committing run `scripts/ci-checks.sh` (fmt, clippy, test, e2e) as a regular user, plus `HOME=$(mktemp -d) SSH_AUTH_SOCK= XDG_RUNTIME_DIR= cargo test --all-targets`.

### Task 1: Shared dropdown

- [ ] Move `Suggestions`, `SUGGESTION_ROWS` and `suggestion_lines` to `src/tui/dropdown.rs` with `pub(super)` visibility; `suggestion_lines` takes the label it indents under.
- [ ] Host form tests pass unchanged.

### Task 2: Tunnel form Host dropdown

- [ ] `TunnelsScreen` keeps the inventory as `Vec<Candidate>` (origin managed or external file) and a `home` for `~`.
- [ ] Typing in Host recomputes the dropdown with `suggest::rank(value, candidates, [])`; an empty value or an exact match closes it unless forced; Ctrl+Space forces it open.
- [ ] Up/Down choose, Enter/Tab pick and close, Esc closes; Tab without it steps to the next field; `host_matches` goes.
- [ ] Form lines splice the dropdown under the Host row; footer shows `Ctrl+Space suggest` on Host and the dropdown footer while open.
- [ ] Tests for each behaviour.

### Task 3: Tabs

- [ ] `enum Tab { Hosts, Tunnels, Containers }`, `UiState::tab`, remove `Mode::Tunnels`, `Focus`, `UiAction::OpenTunnels`; add `UiAction::ShowTab(Tab)`.
- [ ] `tab_key`: when the active tab is browsing (`Mode::Browse`, `TunnelsScreen::is_browsing`, `Panel::is_browsing`), handle `1` `2` `3`, Tab, Shift+Tab, `T`, `c` and `q`.
- [ ] Remove `Leave` from `TunnelAction` and `PanelAction`; Esc no longer leaves.
- [ ] Event loop: on `ShowTab(Tunnels)` reload tunnels; on showing Containers list the target if unlisted; drop the start-up local listing; reload tunnels every 2 s only while the Tunnels tab is shown.
- [ ] Trust prompt opens only on the Hosts tab.
- [ ] Container shell and fix status go to the panel's own status.
- [ ] Render: tab bar line (shortening on narrow widths), then the active tab; tunnels render into an area; the hosts list fills the left column.
- [ ] Footers per spec.

### Task 4: Containers tab

- [ ] `h` opens `picker::Single` with `this machine` and every host; Enter retargets through `show`, Esc closes.
- [ ] F5 lists again; full-size list and details.
